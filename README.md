ATM Simulator (Java):
ATM Simulator is a console-based Java application that recreates the everyday experience of using a bank ATM. Built around a simple menu-driven interface, it lets users check their account balance, deposit money, withdraw cash, and view a mini statement of all their transactions, starting with a default balance of ₹1000.00.
The program is designed to behave like a real banking system. It validates every input, so entering invalid menu options, non-numeric values, or negative amounts is handled gracefully without crashing. Withdrawals are declined when the balance is insufficient, and every successful deposit or withdrawal is recorded in a transaction history that can be viewed at any time. It is written in plain Java using the `Scanner` class for user input and an `ArrayList` for storing transactions, which makes it a great beginner-friendly project for understanding loops, conditionals, switch statements, and basic input handling.
To run the project, clone the repository, compile the file with `javac AtmSimulator.java`, and start it with `java AtmSimulator`. Future improvements could include PIN-based authentication, support for multiple accounts, and persistent storage using files or a database.
